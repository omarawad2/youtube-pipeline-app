youtube-channels-pipeline

youtube-channels-pipeline is a personal automation tool owned and operated by Omar Awad. It uploads videos that he produces himself to his own YouTube channels, using the YouTube Data API v3.

The tool is used with the following seven channels, all owned by the same person:

  • WealthPath Canada
  • WealthPath USA
  • سكة الفلوس
  • سكة الهجرة
  • Northbound - Canada Immigration
  • NorthBound - USA Immigration
  • The Offer Letter - Tech Careers

About this tool

This is a private, single-user tool. It is not a public service, it is not offered to any other person, and it only ever acts on the owner's own YouTube channels and the owner's own video files. It exists so the owner can publish his own videos to his own channels without manually uploading each one.
