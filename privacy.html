Privacy Policy — youtube-channels-pipeline

Effective date: October 21, 2026

youtube-channels-pipeline is a personal automation tool owned and operated by Omar Awad ("the owner"). This policy explains what data the tool accesses, why, and how it is handled.

What data the tool accesses

The tool uses the YouTube Data API v3 with the following scopes:

  • https://www.googleapis.com/auth/youtube.upload — used only to upload the owner's own video files, thumbnails, and caption files to the owner's own YouTube channels.
  • https://www.googleapis.com/auth/youtube.readonly — used only to verify channel identity, i.e. to confirm that an access token belongs to the owner's intended channel before an upload.

The tool accesses only the owner's own YouTube account and channels. It does not access any other person's YouTube account, channel, videos, or data.

Credentials and token storage

OAuth credentials and access/refresh tokens for the tool are stored locally on the owner's own machine. They are never shared with any third party, never sold, never published, and never transferred off the owner's machine except to Google's own API endpoints for the purpose described above.

Third-party data

The tool does not collect, process, store, or share personal data of any third party. It handles only the owner's own video files and the owner's own channel information returned by the YouTube Data API v3.

Advertising and analytics

The tool contains no advertising, no analytics, and no tracking of any kind. This website likewise uses no cookies, no scripts, and no analytics.

Revoking access

The owner can revoke the tool's access at any time by removing it from the third-party access list on the Google Account permissions page (myaccount.google.com/permissions), and/or by deleting the locally stored token files, after which the tool can no longer access the account.

Google API Services disclosure

youtube-channels-pipeline's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
