1 · Add a topic to the funnel

Country topics → pick their channel. A non-country stocks/RE topic added here goes to the picked channel, and the pipeline cross-files it to the other two investing channels on its next pass. The topic gets the next free serial number and lands at the end of that channel's “Open topics”.

2 · Add a channel

Everything syncs automatically — funnel section, channel registry, status card — including the Google consent grant: adding a channel here is your approval for its full wiring, and the consent runs automatically. The only step that can come back to you is a fresh Google security challenge (password / 2-Step code) — the request then shows awaiting-signin and you'll get a message in chat.

4 · Pipeline control

Loading control state…

Run starts production now and sets the loop: a run every 3 days at this same time until you stop it.

Start does not create a separate manual pipeline: it sets the pipeline enabled in the chosen mode, anchors the 3-day loop at the moment you press it, and files a start request that the watcher consumes by running the standard orchestrator pass. The watcher fires each due run after that and advances the loop. Choosing a mode + Start supersedes any run of another mode: only one mode is ever active, and in-flight runs of other modes stop. Stop disables the pipeline (due runs and scheduled passes skip).

Mode notes: muse runs fully on the VM. colab / hybrid starts are best-effort — the watcher prepares everything and launches the Colab session, and you may be asked for a Google sign-in code. YouTube uploads always wait for your per-video approval in chat.
